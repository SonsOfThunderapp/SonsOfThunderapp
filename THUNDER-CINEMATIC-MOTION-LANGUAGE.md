# THUNDER CINEMATIC MOTION LANGUAGE (ETERNITY LOCK)
**Locked:** 2026-08-18  
**Scope:** Slide-based product tour (V11+) and any future tour/Concierge motion  
**Authority:** User directive “Bake it in” — permanent product law

## Governing principle

```
THUNDER SPEAKS
→ ONE FEATURE WAKES UP
→ THE USER'S EYE MOVES THERE
→ THE FEATURE RESPONDS
→ THE MOTION SETTLES
→ CONTINUE
```

Motion **directs attention**. It does not compete for it.

## One dominant motion at a time

Do **NOT** simultaneously:
- move Thunder
- type dialogue
- flash lightning
- animate the background
- pulse several buttons
- animate progress
- and transition the scene

Sequence the choreography like an orchestra: one section leads, others support, then resolve.

Every animation must answer: **What is the user supposed to look at?**  
If unclear → **REMOVE THE ANIMATION**.

Premium > busy. Controlled > chaotic. Purposeful > flashy. Alive > constantly moving.

## Approved motion vocabulary (only these)

### 1. Electric trace reveal
Short controlled electric-yellow/gold trace around a real UI feature edge → resolves into established slower breathing glow.  
**FOCUS DEVICE**, not permanent decoration.

### 2. Focus falloff
When Thunder discusses a feature:
- Thunder stays prominent
- Relevant real feature stays prominent
- Unrelated UI subtly recedes (restrained opacity / depth / soft blur)  
Never make the interface unreadable.

### 3. Thunder entrance
Brief electrical arrival: subtle flash/energy → tiny scale settle → **stationary**.  
Energetic portion ≈ **150–250ms**.  
**NO** bouncing around the screen. **NO** repeated entrance. **NO** cartoon springing.  
Once Thunder arrives, **HE STAYS PUT**.

### 4. Living Thunder idle
While present but not transitioning: approved restrained living-idle only  
- tiny breathing  
- extremely subtle hover  
- occasional sunglasses glint  
- restrained electric aura  
- very small posture movement if supported  

Alive, **not** restless.

### 5. Type-out emphasis
Approved animated type-out. Only important phrases get restrained emphasis:  
LOCK IT IN · YOUR BROTHERS · MEMORIES · THE CODE · ASK ME  
Do not animate every sentence.

### 6. Feature acknowledgement
On successful interact with highlighted element:  
tap compression → tiny rebound → controlled electric confirmation → settle  
Message: **YES. THAT'S IT.** No exaggerated bounce.

### 7. Electric scene transition
Controlled directional electric-energy wipe / streak / dissolve ≈ **300–400ms**.  
Outgoing resolves; incoming appears.  
**NO** Ken Burns. **NO** full-screen zoom. **NO** aggressive camera. **NO** bouncing cards. **NO** random direction changes.

### 8. Subtle depth shift
Background may subtly recede; Thunder + relevant feature stay foreground.  
Careful opacity / depth / soft blur / lighting only.  
**Do NOT** scale/zoom the entire app to manufacture depth.

### 9. Electrified progress
Restrained electrical handoff between progress marks (fraction of a second).  
Do **not** continuously animate all seven indicators.

### 10. Final synchronized heartbeat (Scene 7 only)
When Thunder reaches final “YOU'RE READY. LET'S GO.”:  
Thunder aura + brand energy + LET'S GO CTA → **ONE** restrained synchronized heartbeat/pulse → settle.  
Punctuation mark. **Do not** loop the finale.

---

## Hard rejects (tour motion)

- Ken Burns / continuous whole-screen scaling  
- Full-screen zoom theater  
- Thunder bouncing / traveling around the viewport after entrance  
- Multiple simultaneous dominant motions  
- Confetti, points, social-like celebrations  
- Cartoon spring overshoot  
- Constant flashing / restless idle  

## Reduced motion

`prefers-reduced-motion: reduce` → strip loops, flash, and travel; keep fades and utility state changes only.
